# YAAV (Yet Another Alignment Viewer)

This software is a simple and fast GUI to visualize (and soon edit) large alignments.

## Features

- Smooth. YAAV is implemented in Rust, so it's as fast as solid. GPU-based rendering, culled viewport, custom-built hershey-style glyphs.
- No AI slop. Hand-written line by line. LLMs only contributed to understand tricky parts of the documentation or improve my knowledge of the laguage.
- For everyone. Cross-platform, free, open-source.

## WIP

This software is work in progress. Feel free to open issues for feature requests or bug tracking.
